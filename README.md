# Finance Dashboard UI

## Overview
This is a finance dashboard built using HTML, CSS, and JavaScript. It allows users to track transactions, view financial summaries, and analyze spending.

## Features
- Dashboard summary (Balance, Income, Expenses)
- Transaction table with search
- Role-based UI (Viewer/Admin)
- Add transaction functionality
- Charts (Pie & Line)
- Insights (Highest spending category)
- LocalStorage persistence

## Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js

## How to Run
Open index.html in browser

## Notes
This project uses mock data and frontend-only logic.
